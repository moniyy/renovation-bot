# Бот-заявки для мастера-отделочника «Ремонт под ключ»

Telegram-бот на Node.js (`node-telegram-bot-api`) для приёма заявок от клиентов.

## Возможности

- `/start` — приветствие и главное меню (кнопки «Оставить заявку», «Услуги», «Контакты»), в любой момент сбрасывает текущий опрос
- «Услуги» — список услуг с ориентировочными ценами
- «Оставить заявку» — пошаговый опрос:
  1. Вид работ (кнопки)
  2. Площадь помещения (текстом)
  3. Сроки начала работ (кнопки)
  4. Имя
  5. Телефон
- После опроса клиенту показывается сводка заявки, а владельцу (`ADMIN_ID`) приходит заявка одним сообщением
- Ответы каждого пользователя хранятся отдельно по `chat id`, поэтому опросы разных людей не смешиваются

## Установка и запуск

1. Установите зависимости:

   ```bash
   npm install
   ```

2. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.

3. Узнайте свой Telegram ID (например, у [@userinfobot](https://t.me/userinfobot)) — это будет `ADMIN_ID`, на него будут приходить заявки.

4. Скопируйте файл `.env.example` в `.env` и заполните своими значениями:

   ```bash
   cp .env.example .env
   ```

   ```env
   BOT_TOKEN=ваш_токен_от_BotFather
   ADMIN_ID=ваш_telegram_id
   ```

5. Запустите бота:

   ```bash
   npm start
   ```

   В консоли появится сообщение `Бот запущен и ожидает сообщения...`.

## Структура проекта

- `index.js` — вся логика бота
- `.env` — токен и ADMIN_ID (в репозиторий не попадает, см. `.gitignore`)
- `.env.example` — пример файла с переменными окружения

## Редактирование услуг и цен

Список услуг и цен задан в константе `SERVICES_TEXT` в файле `index.js` — отредактируйте текст под свои реальные услуги и расценки. Там же в `CONTACTS_TEXT` можно поменять контактные данные мастера.
